개인정보처리방침

f1inside-upload · 시행일 2026-10-24

f1inside-upload(이하 “이 도구”)는 유튜브 채널 「F1인사이드」 운영자가 자기 채널에 영상을 올리려고 직접 만들어 쓰는 개인 도구입니다. 이 도구는 YouTube API 서비스를 사용합니다.

1. 사용하는 Google 사용자 데이터

  • YouTube 업로드 권한(youtube.upload) — 운영자의 채널에 영상과 썸네일을 올릴 때만 씁니다.
  • YouTube 계정 읽기 권한(youtube.readonly) — 연결된 채널의 이름·ID를 확인해 다른 채널에 잘못 올리지 않게 하고, 운영자 자기 채널 영상의 공개 숫자(조회수·좋아요·댓글 수)를 읽습니다.
  • YouTube 통계 읽기 권한(yt-analytics.readonly) — 운영자 자기 채널의 통계(시청 시간, 시청 지속률, 구독 증감, 시청자가 들어온 경로, 연령·성별 비율 같은 집계 값, 썸네일 노출·클릭률)를 읽어 운영자만 보는 보고서를 만들 때만 씁니다. 개별 시청자를 알아볼 수 있는 정보는 받지 않습니다.

시청자나 다른 사람의 개인정보는 모으지 않습니다.

2. 보관과 공유

Google 로그인으로 받은 인증 토큰은 운영자의 컴퓨터 안 파일에만 저장되며, 외부 서버로 보내거나 제3자에게 제공·판매하지 않습니다. 통계 보고서도 운영자의 컴퓨터 안에만 저장되고 운영자 본인만 봅니다. 광고나 제3자 분석 목적으로 쓰지 않습니다.

3. 권한 철회와 삭제

언제든 Google 계정 → 보안 → 서드 파티 액세스에서 f1inside-upload 의 접근 권한을 끊을 수 있습니다. 권한을 끊거나 도구 사용을 그만두면 운영자 컴퓨터의 토큰 파일과 저장된 통계를 지웁니다. Google 의 보안 설정 페이지(security.google.com/settings/security/permissions)에서도 철회할 수 있습니다.
