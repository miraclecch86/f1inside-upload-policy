유튜브 채널 「F1인사이드」 운영자가 직접 만든 쇼츠 업로드 도구

f1inside-upload 는 F1 채널 「F1인사이드」의 운영자가 자기 맥에서 쓰는 개인 도구입니다. 운영자가 편집한 쇼츠 영상과 썸네일을 YouTube Data API 로 자기 채널에 올립니다. 일반 사용자에게 제공하는 서비스가 아니며, 다른 사람의 계정이나 채널에는 쓰지 않습니다.

  • 쇼츠 영상 업로드와 공개 예약 (YouTube Data API videos.insert)
  • 쇼츠 썸네일 올리기 (thumbnails.set)
  • 연결된 채널 이름 확인 (channels.list)
  • 올린 영상 상태 확인 (videos.list)

▶ 이 도구는 YouTube API 서비스를 사용합니다 · Uses YouTube API Services — YouTube 서비스 약관

개인정보처리방침 (Privacy Policy) · 이용 약관 (Terms of Service)

f1inside-upload is a personal tool used only by the operator of the YouTube channel “F1인사이드” to upload their own Shorts and thumbnails through the YouTube Data API. It is not offered to the public.
